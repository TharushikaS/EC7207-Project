Parallel Execution Animations

Visualising how a 10 × 10 grid is computed under four different parallelisation strategies.

EC7207 · Group 48 · Tsunami HPC Simulation

1 · Serial

A single thread sweeps the grid cell by cell, row by row. The baseline against which every parallel version is measured.

1 process1 thread

2 · OpenMP

Four shared-memory threads each take a band of rows and compute in parallel within a single timestep. Implicit barrier at the end of each step.

1 process4 threads

3 · MPI

Four processes own four bands in separate memory. Boundary rows are exchanged before each timestep using non-blocking MPI sends/receives.

4 processes1 thread each

4 · Hybrid

Two MPI processes (top and bottom halves), each running two OpenMP threads. MPI between processes, OpenMP within.

2 processes2 threads each
