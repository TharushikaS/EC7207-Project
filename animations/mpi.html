How it works: The grid is split into four horizontal bands, one per MPI process. Each process owns its band in its own private memory. Before each timestep, neighbouring processes exchange halo rows via MPI_Isend/MPI_Irecv (yellow pulse). Then every process sweeps its own band cell-by-cell, sequentially — but all four bands run in parallel. Because each band has only one thread, individual cells within a band light up one at a time, just like the serial version — only now four bands are doing it simultaneously.
