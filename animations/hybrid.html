How it works: Two-level parallelism. MPI splits the grid into 2 horizontal bands — one per process, separate memory. The boundary between them (rows 4–5) is exchanged via MPI halo communication at the start of each timestep (yellow pulse). Inside each band, OpenMP spawns 2 threads that update 2 random cells simultaneously — exactly like the pure OpenMP animation, but confined to each process's band. Net: 4 cells light up per tick (2 in each band), and we cannot say in advance which thread handles which cell.
